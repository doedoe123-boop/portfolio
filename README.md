# Portfolio

Welcome to my personal portfolio website! This site showcases some of my projects and serves as an introduction to my work as a web developer. Feel free to explore and learn more about my skills and projects.

## Live Demo

You can view the live version of the portfolio here: [Your Portfolio Link](https://your-portfolio-link.com)

## Features

- **Hero Section**: A welcoming message with a call-to-action to scroll down.
- **Projects**: Display of various projects including a personal blog, a Laravel API project, and a React Native app.
- **Contact Form**: A simple contact form that allows visitors to get in touch with me directly via email.
- **Footer**: Contains links to my social media profiles like GitHub and LinkedIn.

## Technologies Used

- **HTML5** - Structure of the website.
- **CSS3** - Styling and responsive design using Flexbox and Grid.
- **JavaScript** - Interaction elements like the "Scroll Down" button.
- **Responsive Design** - The website is mobile-friendly and adjusts to different screen sizes using media queries.
- **Email** - Integrated mailto functionality for the contact form.
