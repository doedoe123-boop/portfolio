# Portfolio

Welcome to my personal portfolio website! This site showcases some of my projects and serves as an introduction to my work as a web developer. Feel free to explore and learn more about my skills, projects, and journey.

## Live Demo

You can view the live version of the portfolio here: [Portfolio Link](https://nelson-dev.vercel.app)

## Features

- **Interactive Hero Section**: A visually appealing hero section with **Particles.js**, creating a dynamic and engaging background effect.
- **About Section**: A dedicated section to introduce myself, my hobbies, and aspirations.
- **Projects Showcase**: A categorized display of projects including personal blogs, Laravel API projects, and a React Native app.
- **Skills Section**: Categorized skills displayed with progress bars and visually separated for clarity.
- **Timeline**: Highlights key milestones in my journey as a web developer.
- **Contact Form**: A simple and responsive contact form powered by Formspree to get in touch directly.
- **Footer**: Contains links to my GitHub, LinkedIn, and email with hover effects for better engagement.

## Technologies Used

### Core Technologies

- **HTML5** - Structure of the website.
- **CSS3** - Styling and responsive design using Flexbox and Grid.
- **JavaScript** - Interaction elements like the "Scroll Down" button and dynamic animations.

### Libraries and Tools

- **Particles.js** - Interactive particle animations in the hero section.
- **Formspree** - Email handling for the contact form.

### Responsive Design

- The website is fully responsive and adapts seamlessly to different screen sizes using media queries.

### Additional Features

- **Hover Effects**: Animations for buttons, photos, and links to enhance user engagement.
- **Dynamic Backgrounds**: Hero section with a vibrant and interactive particle animation for a polished and modern aesthetic.
